# PharmacoPilot 教师试用指南(S1 课前诊断 v0.1)

面向试用教师,不涉及任何工程细节。读完即可独立完成一次"导入前测 → 生成诊断 → 裁决 → 发布"的完整流程。

## 1. 这个系统是什么

PharmacoPilot 是《药事管理学》课程的教学智能体。本次试用的 **S1 课前诊断** 功能:

- 导入一份课前小测(题目 + 学生作答,CSV 格式);
- 系统自动算出班级掌握情况(各知识点得分率等"事实");
- 基于事实自动起草诊断结论与教学建议;
- **每一条结论都由您逐条裁决**(采纳 / 修改后采纳 / 否决 / 暂缓),系统绝不替您做决定;
- 裁决后一键发布,生成留档的诊断报告版本,全程操作可在"审计时间线"中回看。

**它不会做的事(请知悉):**

- 不会自动修改您的裁决结果;您"修改后采纳"时,系统原文与您的修改稿**都保留**,原文只字不动;
- 不会联网、不会把数据传出本机——全部数据保存在运行它的这台电脑上;
- 学生数据只认"匿名编号"(如 S01、S02),**请不要填写真实姓名、学号**(见第 4 节);
- 不做自动评分排名,不给学生个体贴标签;输出仅供您备课参考。

## 2. 启动系统

二选一:

- **双击启动器**:双击项目文件夹里的 `启动3D教室.command`,终端窗口会显示本地地址(默认 `http://localhost:4173`,端口被占用会自动顺延)并自动打开浏览器。
- **命令行**:在项目文件夹内执行 `npm start`,看到监听端口提示后用浏览器打开 `http://localhost:4173`。

停止:回到终端窗口按 `Ctrl+C`,或直接关掉终端窗口。

## 3. 令牌登录

1. 管理员会发给您一串以 `pk_` 开头的试用令牌(只显示一次,请妥善保存,不要转发);
2. 打开 **`http://localhost:4173/s1-workspace.html`**(S1 教师审核工作区);
3. 把令牌粘贴进页面顶部的 Token 输入框,点 **保存 Token**;之后页面会自动带上您的身份。
4. 令牌丢失或疑似泄露:联系管理员撤销并重新签发(您自己无法撤销)。

## 4. 准备前测 CSV(重要:匿名纪律)

在工作区第 1 步区域点 **下载题目模板**、**下载作答模板**,用 Excel/表格软件填写后另存为 CSV(UTF-8 编码)。

- **题目 CSV** 列:`item_no`(题号)、`stem`(题干)、`options`(选项字母,如 `A|B|C|D`)、`correct_option`(正确选项字母)、`knowledge_tags`(知识点标签,多个用 `;` 分隔);可选 `optionTexts`(选项文字,格式 `A:文本|B:文本`)。
- **作答 CSV** 列:`student_anon_id`(学生匿名编号)、`item_no`(题号)、`selected_option`(该生所选字母)、`participated`(是否参与,1/0);可选 `knowledge_level`、`experience_profile`。

**匿名纪律(必须遵守):**

- `student_anon_id` 只允许字母、数字、`-`、`_`,2–64 位(如 `S01`、`S02`);
- **绝对不要**填真实姓名、学号、手机号;请您在线下自行保管"编号 ↔ 学生"对照表,系统内不留任何可识别信息。

## 5. 一次完整流程

在工作区页面自上而下操作:

1. **建课 / 建班 / 建课时**:填入课程、班级、课时信息(首次使用各建一次,之后复用);
2. **创建诊断工作流**:每个课时的每轮诊断对应一条工作流;
3. **导入前测**:上传或粘贴两份 CSV。若该课时已导入过,需要勾选"确认重新导入"并知晓会重算;
4. **算事实**:一键计算班级事实(各知识点得分率等);
5. **生成诊断内容**:系统基于规则起草"事实 / 推断 / 建议"三类条目,每条附证据;
6. **校验并进入审核**:系统自动跑机械校验与语义审查,全绿才能进入裁决;
7. **逐条裁决**(四键):
   - **采纳**:原样采用;
   - **修改后采纳**:填写您的修改稿;系统原文保留不动,发布稿用您的修改版,时间线同时留有两版;
   - **否决**:该条不进报告;
   - **暂缓**:本次不定,列入"待议问题";
8. **发布新版本**:生成带版本号的诊断报告(v1、v2……),旧版本永远可回看,不会被覆盖;
9. **审计时间线**:点"加载审计事件"回看本轮全部操作——每一步是什么时间、谁做的、结果如何,都有留档。同一件事的重复记账已自动合并(显示为一条主事件 + 别名计数)。

## 6. 知识库检索与审核(入口)

课程知识库支撑诊断内容的证据检索:

- 检索接口:`POST /api/product-core/kb/retrieve`(按课程/章节/关键词检索知识单元与原文片段);
- 单元审核接口:`POST /api/product-core/kb/units/:layer/:id/review`(状态机:machine_extracted → needs_review → teacher_verified / rejected);
- 目前无独立图形页面,试用期间如需检索或审核知识库,请告知管理员协助操作。

## 7. 常见问题

- **替换前测数据后报 `OBSERVATION_RECALC_MISMATCH`**:同一计算版本号下重算结果与已存档事实不一致——通常是替换了作答数据但仍沿用旧的"计算版本"。请勾选重新导入确认后重试;若仍报此错,联系管理员处理(这是防静默篡改的保护,不是您的操作失误)。
- **提示令牌无效 / 401**:检查 Token 是否完整粘贴(以 `pk_` 开头);确认无误仍失败,找管理员核对令牌是否被撤销。
- **端口打不开页面**:看终端窗口里实际打印的端口号(被占用会自动 +1),用新端口访问。
- **令牌丢了 / 想换人用**:令牌无法找回,只能由管理员撤销旧令牌、签发新令牌。
- **数据会丢吗**:不会自动丢。所有数据在本机 `.pharmaco-data` 文件夹;试用间隙管理员可能做"归档式重置"(旧数据改名保留,不删除),重置后看到的是全新空库,属预期。
- **想让系统"记住"我的修改习惯**:当前版本不做个性化学习,每条结论独立裁决。
