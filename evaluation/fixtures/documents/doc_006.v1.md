# S1 学情诊断实施说明

S1 阶段是教学流程的起点,其主要任务是基于前测数据完成学情诊断,为后续教学决策提供事实依据。

<!-- page -->

前测题目应当在开课前发布,学生作答数据仅以匿名内部标识存储,不得记录任何可识别身份的信息。

<!-- page -->

学情诊断结论应当区分班级整体水平与个体差异,并明确标注每项结论的证据来源。
