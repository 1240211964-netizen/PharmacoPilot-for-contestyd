# 学习分析与教学评价

学情是指学习者在特定学习阶段的知识基础、能力水平与学习特征的总和。

<!-- page -->

教学评价是依据教学目标,对教学过程与学习结果进行价值判断的活动。

<!-- page -->

在药学服务实践中,药师应当综合运用专业知识与沟通技巧,为患者提供个体化的用药指导,并持续关注用药后的疗效与安全性。
