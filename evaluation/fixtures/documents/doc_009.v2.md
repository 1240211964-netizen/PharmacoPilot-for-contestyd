# 药品集中采购与供应管理规范(2024年修订)

药采规〔2021〕5号

第一条 为规范药品集中采购与供应管理工作,保障临床用药供应,制定本规范。

第五条 医疗机构应当优先采购和使用中选药品,并按约定完成采购量。

<!-- page -->

第八条 中选药品的采购数据应当按季度汇总后报送省级集中采购平台。

第九条 医疗机构应当建立中选药品使用情况监测机制,定期评估供应保障能力。

第十条 本规范自2024年1月1日起施行,原2021年版同时废止。
