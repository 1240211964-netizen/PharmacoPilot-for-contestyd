# S1 学情诊断量表

本量表用于 S1 阶段学情诊断,依据匿名化前测数据与课堂观察记录对班级学情进行分级判定。

<!-- page -->

## 判定标准

| 指标 | 阈值 | 判定 |
| --- | --- | --- |
| 前测正确率 | 低于60% | 判定为基础薄弱 |
| 前测正确率 | 60%至85% | 判定为部分掌握 |
| 前测正确率 | 高于85% | 判定为熟练掌握 |
| 课堂参与率 | 低于50% | 需调整教学策略 |

量表结果仅供任课教师进行教学决策参考,不得用于对学生的评价。
