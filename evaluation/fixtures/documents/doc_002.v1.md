# 第三章 药品不良反应与监测

药品不良反应是指合格药品在正常用法用量下出现的与用药目的无关的有害反应。

<!-- page -->

药品不良反应监测是指对上市药品的不良反应进行收集、分析、评价和控制的过程。

对于治疗窗窄、个体差异大的药物,应当开展治疗药物监测,以保障用药安全。

<!-- page -->

# 第四章 药事管理概述

药事管理是指对药学事业的综合管理,涵盖药品研制、生产、经营、使用等环节的监督与管理。
